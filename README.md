# 🎅 Santa Tracker

크리스마스이브에 산타의 위치를 보여주는 ESP32-C3 키링입니다.
An ESP32-C3 keychain that tracks Santa on Christmas Eve.

- 📘 제작 가이드 / Build guide: [한국어](docs/SantaTracker_Guide_Kor.pdf) · [English](docs/SantaTracker_Guide_Eng.pdf)
- 🖨️ 케이스 / Case: [MakerWorld](https://makerworld.com/en/models/3655350-santa-tracker-esp32-c3-keychain)

> 📌 산타 경로는 구글 산타 추적기 공개 경로(2019년 일정)를 기반으로 합니다. 12월 이후 경로 데이터가 업데이트될 수 있습니다.
> The route is based on Google Santa Tracker's public route (2019 schedule) and may be updated after December.

## 준비물 / Parts

- [ESP32-C3 1.44" display board](https://a.aliexpress.com/_c3lGvTS5) (300mAh 배터리 포함 옵션 / with the battery option)
- [TTP223 touch sensor](https://a.aliexpress.com/_c3BY0IdB) (1개 사용 / only 1 needed)
- [M2×10 screws ×4](https://link.coupang.com/a/iQ55wgyWBw) (같은 규격이면 무엇이든 / any M2×10)
- [26 AWG wire ×3](https://link.coupang.com/a/iQ58ddroTA) (얇은 전선이면 무엇이든 / any thin wire)
